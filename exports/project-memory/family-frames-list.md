Agreed 2026-11-22 between the research thread and the catalog/site thread after Christian asked for Baptist and other Christian lenses, an S-F tier grade, a pragmatist lens, an individualism vs communalism axis, and said "lower is better?" was unclear.
- UPDATE later 2026-11-22: now 31 frames in 3 groups (Christian / Other faiths / Non-theistic and philosophical), adding Seventh-day Adventist, Jehovah's Witness, Christian Science, Shinto, Sikh, Bahá'í, Scientologist, Wiccan / Pagan, Satanist (non-theistic CoS/TST), Unitarian Universalist, and Jewish split into Orthodox / Conservative / Reform Jewish. Exact names = first heading of each guide in /mnt/project-files/frame-guides/. Each guide gets a "## Summary" (values, forbids, family/sex, stories & art, range, own sources). One single frames table per entry.
- Original frames (19, exact names in /mnt/project-files/frame-guides/FRAMES.md, which is the source of truth): Catholic; Eastern Orthodox; Baptist; Non-denominational Evangelical; Pentecostal / Charismatic; Reformed / Presbyterian; Lutheran; Methodist / Wesleyan; Anglican / Episcopal; Anabaptist (Mennonite, Amish, Brethren); Latter-day Saint; Mainline progressive Protestant; Jewish; Muslim; Hindu; Buddhist; Secular progressive; Secular humanist; Conservative / traditional.
- Each frame row has Grade S-F from that tradition's view. This is how "best shows under each ideology" is ranked.
- Grade rule (revised 2026-11-22 after Christian noted the Bible would grade badly if graphic): Grade = message fit only (endorse vs depict, evil framed as evil, consequences, redemption, treatment of the sacred), per each tradition's documented teaching on art/media; never lowered by intensity alone. Separate column "Depiction concern" (Minor/Discuss/Significant, formerly "Weight") = how the tradition views explicitness itself. Column order: Frame | Grade | Depiction concern | What aligns | What may concern | Talking points.
- Content scores stay 0-10 intensity only (higher = more of it, not better/worse); no letter grade there, to stay neutral.
- Lens table has Closeness (S-F); new lenses Pragmatism, Communitarianism, Confucian ethics (33 total).
- 4th axis row: "Community (0 individual first, 10 community first)".
- Message delivery (Christian, 2026-11-23): each entry has "## Message delivery" before Creator and publisher context: Style (Subtle/Woven in/Explicit/Heavy-handed), Preachiness 0-10, Opposing views (Fair/Mixed/Strawman/None shown), Evidence (25 words), Note, plus 0-4 rows Character | Ideology | Role | Treatment. Heavy-handed/Strawman only with review support. build.py parses it; quick entries use the "delivery" JSON block.
- Site shows a labeled "provisional" grade for entries without grades.
Spec: /mnt/project-files/manga-entries/TEMPLATE-INSTRUCTIONS.md.

**Why:** neutral, denomination-level nuance and a parent-friendly ranking.
**How to apply:** every new or re-run deep entry follows this; old entries get it on re-run.
